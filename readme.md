Se desarrolló una skill con el objetivo de orientar a la IA sobre cómo responder ante consultas relacionadas con los contenidos de la materia. Para ponerla a prueba, se utilizaron los ejercicios 2 y 3 del Práctico 3, ya que consideré que eran los más adecuados para evaluar el funcionamiento de la skill y comprobar si las respuestas generadas se ajustaban a los criterios trabajados en clase.

Además, se le proporcionó todo el material bibliográfico y teórico brindado por la cátedra, con el objetivo de que la IA pudiera trabajar con un mayor contexto y fundamentar sus respuestas a partir de los contenidos correspondientes a la materia.

En este `Repositorio` se incluye todo el material utilizado durante el desarrollo y prueba de la skill, la propia skill, el prompt utilizado para indicarle a la IA cómo emplearla y el material proporcionado por la cátedra.

También se adjunta el enlace al chat en el que se realizó la prueba, por si resulta de utilidad para revisar el proceso seguido y observar cómo se aplicó y evaluó la skill.
